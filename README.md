## 🌐 التحكم عن بعد (فتح/إغلاق أي طالب بأي وقت)

كل طالب يحصل عند التسجيل على **رقم تعريفي خاص** (مثل `GF-AB12X`) يظهر له فوراً ويُرسله لك عبر الواتساب، ويظهر أيضاً تلقائياً داخل تقريره الشهري.

لوحة التحكم: **`admin/index.html`** (تُفتح من أي متصفح، على الموبايل أو الكمبيوتر، بعد رفع المستودع ليصبح لها رابط مباشر عبر GitHub Pages).

من خلالها تقدر:
- **تفتح أو توقف وصول طالب معين** فوراً (باستخدام رقمه التعريفي)، مع إمكانية تحديد تاريخ انتهاء.
- **توقف التطبيق على كل الطلاب دفعة واحدة** (زر إغلاق شامل) — مفيد مثلاً وقت الصيانة.
- إضافة ملاحظة تظهر للطالب عند الإغلاق (مثل "تواصل معي أولاً").

**كيف تعمل تقنياً:** اللوحة تعدّل ملف `remote-config.json` في المستودع عبر GitHub مباشرة. التطبيق يفحص هذا الملف تلقائياً (كل عدة ساعات، وأيضاً عند فتح التطبيق من جديد) طالما فيه انترنت، ويطبّق قرارك فوراً — حتى لو كان الطالب أدخل كود التفعيل الصحيح من قبل.

**أول استخدام:** تحتاج "GitHub Token" خاص بك (يُشرح داخل اللوحة نفسها كيف تولّده بخطوتين) — يُحفظ على جهازك فقط ولا يراه أحد.

> الكود **ثابت** لجميع الطلاب كما طُلب. لا يفتح الطالب التطبيق إلا بعد مراجعتك عبر واتساب وأخذ الكود منك.

## 📤 متابعة الطالب عن بُعد

في الصفحة الرئيسة زرّ واحد: **«إرسال تقريري الشهري عبر واتساب»**.
بضغطة واحدة يفتح واتساب برسالة جاهزة إلى رقمك تحوي:

- اسم الطالب ومدرسته وفرعه وفترة التقرير
- عدد الوحدات المُنجزة ومتوسط الاختبارات وأيام الدراسة
- **المستوى في كل مهارة** بالألوان 🟢🟡🔴
- **«أحتاج شرحاً إضافياً في: …»** — قائمة المهارات الضعيفة
- آخر ٨ اختبارات بنتائجها وتواريخها
- عدد الوحدات التي لم يجتزها
- **كود تحقّق** في آخر التقرير يمنع تعديل الأرقام يدوياً

ويذكّر التطبيق الطالب تلقائياً كل ٢٨ يوماً بإرسال تقريره.

**لوحة المعلم:** من أيقونة 🔑 في أعلى الصفحة الرئيسة، أدخل كود المعلم لترى على جهاز الطالب مباشرةً كل إحصاءاته وسجل اختباراته، مع زرّ نسخ التقرير كاملاً.

## 📱 توليد ملف APK

المشروع جاهز للبناء. اختر إحدى طريقتين:

### الطريقة الأولى — عبر GitHub (بلا أي برامج، مجاناً) ✅ الأسهل
1. أنشئ حساباً على <https://github.com> ثم مستودعاً جديداً (Repository) وسمِّه `godfather-english`.
2. ارفع محتويات هذا المجلّد كاملاً إلى المستودع (زر **Add file → Upload files**، ثم اسحب المجلّدات).
3. ادخل تبويب **Actions** في المستودع، واضغط **I understand my workflows, go ahead and enable them**.
4. اختر من اليسار **«بناء ملف APK — عرّاب الانجليزي»** ثم اضغط **Run workflow**.
5. انتظر نحو ٥ دقائق، ثم افتح التشغيل المنتهي ونزّل الملف من قسم **Artifacts** باسم `GodfatherEnglish-APK`.
6. فكّ الضغط عن الملف المُنزَّل، وستجد داخله `app-release.apk` — هذا هو ملف التثبيت.

### الطريقة الثانية — على كمبيوترك
1. نزّل **Android Studio** من <https://developer.android.com/studio> وثبّته (يُنزّل معه كل ما يلزم).
2. من قائمة **File → Open** اختر المجلّد `android` من هذا المشروع.
3. انتظر حتى ينتهي الـ Gradle Sync (أول مرة تحتاج وقتاً لتنزيل المكتبات).
4. من القائمة: **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
5. يظهر إشعار فيه **locate** — اضغطه ليفتح مجلّد الملف:
   `android/app/build/outputs/apk/debug/app-debug.apk`

> **ملاحظة مهمّة:** إذا عدّلت أي محتوى داخل مجلّد `www`، انسخه مرّة أخرى إلى
> `android/app/src/main/assets/www` قبل البناء (طريقة GitHub تفعل ذلك تلقائياً).

### تثبيت الـ APK على الهاتف
انقل الملف إلى الهاتف، افتحه، وإذا ظهرت رسالة «تثبيت من مصادر غير معروفة» فعّل السماح للتطبيق الذي تفتح منه الملف، ثم أكمل التثبيت.

## 💻 نسخة تعمل فوراً بلا بناء

الملف **`عراب_الانجليزي_نسخة_واحدة.html`** هو التطبيق كاملاً في ملف واحد يعمل **بلا إنترنت**.
أرسله لأي طالب عبر واتساب، يفتحه بمتصفّح Chrome على هاتفه، ثم من قائمة المتصفّح يختار **«إضافة إلى الشاشة الرئيسية»** فيصبح كالتطبيق تماماً، ويحفظ تقدّمه، وزرّ إرسال التقرير يعمل بشكل طبيعي.
استعمله ريثما يُبنى ملف الـ APK، أو للطلاب الذين يصعب عليهم تثبيت التطبيقات.

## ✏️ كيف تضيف وحدة أو تعدّل سؤالاً؟

كل وحدة كائن في ملف القسم، بهذا الشكل:

```js
{ id:'s13', t:'New Unit', ta:'الوحدة 13 — عنوانها بالعربية', tag:'وصف قصير',
  blocks:[
    {type:'text',  html:'فقرة شرح بالعربية ...'},
    {type:'h',     ico:'📐', t:'عنوان فرعي'},
    {type:'box',   kind:'rule', t:'قاعدة', html:'نصّ القاعدة'},   // kind: rule|tip|warn|note|ex
    {type:'vocab', items:[['word','المعنى']]},
    {type:'table', head:['عمود','عمود'], rows:[['خلية','خلية']]},
    {type:'steps', items:['خطوة أولى','خطوة ثانية']},
    {type:'dialog',lines:[['Sara','English line','الترجمة']]},
    {type:'drill', items:['سؤال تدريبي'], answers:'الإجابات'}
  ],
  quiz:[
    { q:'نصّ السؤال', o:['خيار','خيار','خيار','خيار'], a:1,
      sk:'grammar',            // grammar | vocab | reading | writing | pron | func
      e:'شرح سبب الإجابة الصحيحة' }
  ]
}
```

لكتابة كلمة إنجليزية داخل نصّ عربي استعمل `<span class="en">word</span>` حتى تظهر باتجاهها الصحيح، وللجملة الكاملة `<span class="en-blk">sentence</span>`.

بعد أي تعديل، افتح `www/index.html` في المتصفّح للتأكّد أنّ كل شيء يعمل قبل بناء الـ APK.
